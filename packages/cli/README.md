# skill-organizer CLI

`skill-organizer` keeps nested `SKILL.md` trees organized while exposing the flat first-level skills directory that agent tools expect.

## Install

- GitHub Releases: https://github.com/sergiocarracedo/skill-organizer/releases
- npm: `npm i -g skill-organizer`

## Verify

```bash
skill-organizer --version
```
