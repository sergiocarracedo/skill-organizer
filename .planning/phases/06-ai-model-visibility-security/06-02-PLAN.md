# Plan 06-02: Model selection in tool picker + --model flag + persistence

## Objective

Wire model selection into the agent tool picker flow. After the user selects a tool, if the tool exposes available models (ListModels != nil), show the model list and let the user pick. Add `--model` flag to `check-security` and `check-overlap`. Save the selection. Show the current model in `telemetry status`.

## Context

Plan 06-01 added the infrastructure: each tool knows how to query its models. Now we need the user-facing flow. The model selector reuses the same `selectOption` / `ToolSelector` pattern already used for tool selection. The `--model` flag follows the same pattern as `--tool`.

## Tasks

### Task 1: Add model selection to chooseAgentToolImpl

<files>
- packages/cli/internal/agenttools/agenttools.go
- packages/cli/internal/agenttools/agenttools_test.go
</files>

<action>
Modify `chooseAgentToolImpl` to handle model selection after a tool is chosen:

```go
func chooseAgentToolImpl(installed []InstalledTool, cfg configpkg.AgentSelectionConfig, explicitID string, choose bool, selector ToolSelector) (InstalledTool, configpkg.AgentSelectionConfig, error)
```

Add a `explicitModel string` parameter for the `--model` flag value (empty string if not set).

Flow after tool is selected:
1. If `explicitModel != ""`: use it as `cfg.DefaultModel`, return.
2. If tool's `ListModels` is nil: skip model selection (no models available).
3. Call `QueryToolModels(selectedTool)` to get available models.
4. If query returns error: log warning, skip model selection.
5. If models list is empty: skip model selection.
6. If `cfg.DefaultModel` is in the models list: use it (silent, no prompt).
7. Otherwise: prompt user to pick a model using the `selector` callback with model labels (e.g. "Anthropic/claude-sonnet-4-20250514").
8. Save selected model as `cfg.DefaultModel`.

Update the `ChooseAgentTool` signature and `ChooseAgentToolFunc` to pass `explicitModel string`.

Update all callers of `ChooseAgentTool`:
- `cmd/skill_security.go` — pass `securityModelID` (the `--model` flag value)
- `cmd/skill_overlap.go` — pass `overlapModelID` (the `--model` flag value, added in Task 3)

Add tests:
- `TestChooseAgentTool_SelectsModelWhenToolExposesModels`: tool with ListModels returns models, user picks one.
- `TestChooseAgentTool_NoModelPromptWhenToolHasNoModels`: tool with ListModels: nil skips model step.
- `TestChooseAgentTool_UsesDefaultModel`: default model matches available list, no prompt.
- `TestChooseAgentTool_ExplicitModelFlag`: explicitModel is set, used as DefaultModel.
- `TestChooseAgentTool_ModelQueryErrorShowsToolWithoutModel`: ListModels returns error, skip gracefully.

All new tests use swappable vars (`ChooseAgentToolFunc`, `QueryToolModelsFunc`, etc.).
</action>

<verify>

- Model selection flow works for tools with models
- Model selection skipped gracefully for tools without
- All tests pass
</verify>
